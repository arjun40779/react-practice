# react-practice

A minimal React, TypeScript, and Vite todo app. Tasks are saved in the
browser's local storage.

## Getting started

Install dependencies and start the development server:

```sh
bun install
bun dev
```

Open the local URL printed by Vite. The todo list is available at `/todo`.

## Scripts

- `bun dev` starts the development server with hot module replacement.
- `bun run build` type-checks the app and creates a production build.
- `bun run lint` runs Oxlint.
- `bun run preview` serves the production build locally.
